# Machine Learning for Digital Scholarly Editions 2026


The repository contains the official website of the Summer School with the programme deployed under [https://dhgraz.github.io/dse-ml-2026](https://dhgraz.github.io/dse-ml-2026). 

Under the folder "[materials](https://github.com/DHGraz/dse-ml-2026/tree/main/materials)" you can find the slides, jupyter notebooks and data used during the Summer School.
